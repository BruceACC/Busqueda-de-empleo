Para buscar vacantes automáticamente necesitas una API Key gratuita de RapidAPI.

  2. Suscríbete al plan Basic (gratis) de JSearch API
  3. Copia tu API Key
  4. Pégala en el archivo .env → RAPIDAPI_KEY=tu_key
  5. Reinicia el servidor
